settings.json ​

这一页列出所有用户可配置的设置、类型、默认值和作用。

  • 用户级：~/.nek/agent/settings.json
  • 项目级：.nek/settings.json（信任项目后加载）

项目设置覆盖用户设置；对象类型的设置递归合并；资源列表合并。大多数常用设置也可以在 /settings 里修改。手动编辑文件后运行 /reload。

nek 独有功能（Plan、Todo、子代理）的配置不在这里，而在 nek.yaml。

默认配置 ​

默认不需要创建这个文件；文件不存在或内容为以下空对象时，使用本页列出的内置默认值：

json
{}

公共版本不附带个人 settings、固定服务商、代理地址或独立的压缩模型设置。登录后用 /model 选择自己的模型；只需把想覆盖的设置写入本机文件，例如：

json
{
  "tuiMode": "regular"
}

上面的普通终端模式只是可选示例，实际默认值仍是 "fullscreen"。

设置类型默认值说明
defaultProviderstring自动启动时的服务商

modelThinkingLevelsobject无按模型设置启动思考等级，键为精确的 服务商/模型ID
thinkingBudgetsobject内置值minimal、low、medium、high 各等级的 token 预算

showCacheMissNoticesbooleanfalse显示明显的缓存未命中、缓存预热成功、压缩用量、服务商恢复等提示
cacheWarming"off" | "streaming" | "idle""streaming"在运行期间（streaming）或运行之间（idle）保持服务商的提示词缓存不过期。只能在用户级设置

缓存预热只在模型声明了缓存有效期（见 提示词缓存有效期），且 nek 估计能避免至少 0.05 美元的缓存未命中费用时才进行。预热产生的用量计入会话总量，但不进入模型上下文。/session 会显示下一次的预热决定。

工具 ​

设置类型默认值说明
defaultToolsstring[]read、bash、edit、write、grep、find、ls、ast_grep、web_search启动时启用的内置工具。空数组表示不启用任何内置工具（扩展和 SDK 工具不受影响）

可用的内置工具：read、bash、powershell、edit、write、grep、find、ls、ast_grep、web_search。nek 扩展的工具（todo_write、subagent 等）不受 defaultTools 控制。

/reload 会启用新加入 defaultTools 的工具，保留被移除的工具，不会重新启用本会话中手动禁用且未改变的工具。命令行的工具参数（--tools 等）优先于这个设置，包括 reload 时。

设置类型默认值说明

compaction.reserveTokensnumber16384为模型回复预留的 token
compaction.keepRecentTokensnumber20000原样保留、不做总结的近期 token
compaction.modelOverridesobject无按模型设置上面两项，键为精确的 服务商/模型ID

网络与重试 ​

设置类型默认值说明
transport"auto" | "sse" | "websocket" | "websocket-cached""auto"支持多种传输方式的服务商优先使用的传输
httpProxystring无代理地址，作为 HTTP_PROXY 和 HTTPS_PROXY 用于 nek 管理的 HTTP 客户端。只能在用户级设置
httpIdleTimeoutMsnumber300000HTTP 响应头和响应体的空闲超时（毫秒），0 关闭
websocketConnectTimeoutMsnumber15000WebSocket 连接超时（毫秒），0 关闭
retry.enabledbooleantrue对临时错误自动重试
retry.maxRetriesnumber3最大重试次数
retry.baseDelayMsnumber2000指数退避的初始延迟（毫秒）
retry.maxAgentDelayMsnumber60000单次重试的最大延迟（毫秒）
retry.provider.timeoutMsnumber同 httpIdleTimeoutMs服务商请求超时（毫秒）
retry.provider.maxRetriesnumber0服务商 SDK 层面的重试次数
retry.provider.maxRetryDelayMsnumber60000服务端要求的最大等待时间（毫秒），0 不限制

retry.provider.maxRetries 除非确有需要请保持 0：服务商层面的重试会推迟 nek 自己处理额度和用量限制错误。

可重试的临时错误包括：过载、限流、5xx、连接中断（包括流在完成前断开）、model is at capacity 等。Retry-After 无法解析时使用指数退避。上游卡住但没有断开连接时，nek 要等到 httpIdleTimeoutMs 才会报错并重试。

资源 ​

用户设置中的资源路径从 agent 目录解析，项目设置中的从项目 .nek 目录解析。支持绝对路径和 ~。

设置类型默认值说明
extensionsstring[][]扩展文件或目录
skillsstring[][]Skill 文件或目录
promptsstring[][]提示词模板文件或目录
themesstring[][]主题文件或目录
enableSkillCommandsbooleantrue把 Skills 注册为 /skill:名字 命令

资源数组支持：

  • !pattern：用 glob 排除；
  • +path：精确包含；
  • -path：精确排除。

这些规则也作用于自动发现的资源。例如在项目里禁用某个用户级扩展：

json
{
  "extensions": ["-~/.nek/agent/extensions/noisy.ts"]
}
