快捷键 ​

nek 的快捷键绑定在一个个命名的动作上（例如 app.session.new）。你可以修改默认绑定，或给没有默认按键的动作绑定按键。

在 nek 里运行 /hotkeys 查看输入框和应用当前生效的快捷键。

修改快捷键 ​

创建 ~/.nek/agent/keybindings.json，把动作 ID 映射到一个按键或按键列表：

json
{
  "app.session.new": "ctrl+shift+n",
  "app.session.tree": ["ctrl+shift+t", "alt+shift+t"]
}

配置的值替换该动作的默认绑定。用空列表禁用一个动作的所有按键：

json
{
  "tui.altScreen.pageUp": []
}

修改后运行 /reload 应用到当前会话。

切换 Plan 模式的快捷键（默认 alt+m）不在这里，而在 nek.yaml 的 plan.shortcut。

按键写法 ​

格式为 修饰键+键。修饰键有 ctrl、shift、alt、super，可以组合使用。可用的键：

  • 字母：a-z
  • 数字：0-9
  • 特殊键：escape、esc、enter、return、tab、space、backspace、delete、insert、clear、home、end、pageUp、pageDown、up、down、left、right
  • 功能键：f1-f12
  • 符号：`、-、=、[、]、\、;、'、,、.、/、!、@、#、$、%、^、&、*、(、)、_、+、|、~、{、}、:、<、>、?

例如：ctrl+shift+x、alt+ctrl+x、ctrl+shift+alt+x、super+k、ctrl+super+k、ctrl+1。

super 组合需要终端单独上报这个修饰键（通常通过 Kitty 键盘协议），不支持的终端里可能无效。

输入框 ​

光标移动 ​

动作 ID默认按键说明
tui.editor.cursorUpup光标上移；在首行时浏览更早的历史
tui.editor.cursorDowndown光标下移；在末行时浏览更新的历史
tui.editor.historyPrevious无上一条历史提示词（不论光标位置）
tui.editor.historyNext无下一条历史提示词
tui.editor.cursorLeftleft、ctrl+b左移
tui.editor.cursorRightright、ctrl+f右移
tui.editor.cursorWordLeftalt+left、ctrl+left、alt+b左移一个词
tui.editor.cursorWordRightalt+right、ctrl+right、alt+f右移一个词
tui.editor.cursorLineStarthome、ctrl+home、ctrl+a到行首
tui.editor.cursorLineEndend、ctrl+end、ctrl+e到行尾
tui.editor.jumpForwardctrl+]向前跳到指定字符
tui.editor.jumpBackwardctrl+alt+]向后跳到指定字符
tui.editor.pageUppageUp、ctrl+pageUp向上翻页
tui.editor.pageDownpageDown、ctrl+pageDown向下翻页

专用的历史动作优先于使用相同按键的应用动作。

应用 ​

动作 ID默认按键说明
app.interruptescape取消 / 中止
app.clearctrl+c第一次清空输入框，第二次退出
app.exitctrl+d输入框为空时退出
app.suspendctrl+z（Windows 无）挂起到后台
app.editor.externalctrl+g在外部编辑器中编辑（externalEditor、$VISUAL、$EDITOR，Windows 默认记事本，其他系统默认 nano）
app.clipboard.pasteImagectrl+v（Windows/WSL 为 alt+v）从剪贴板粘贴图片或文字

原生 Windows 上 app.suspend 没有默认按键，因为 Windows 终端不支持 Unix 作业控制。手动绑定后 nek 只会显示一条状态信息而不会挂起。WSL 使用正常的 ctrl+z 和 fg。
