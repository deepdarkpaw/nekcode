# 斜杠命令

在 nek 的输入框里输入 `/` 可以搜索当前会话可用的命令。这一页列出内置命令。扩展、提示词模板和 Skills 也会添加命令，所以 `/` 菜单才是你当前会话的准确清单。

## 模型与设置

| 命令 | 说明 |
|---|---|
| `/settings` | 打开设置 |
| `/model [服务商/模型]` | 选择模型；带参数时直接切换 |
| `/thinking [等级]` | 设置思考等级 |
| `/scoped-models` | 设置 `Ctrl+P` 循环使用的模型 |
| `/login [服务商]` | 添加服务商认证 |
| `/logout` | 删除服务商认证 |

## Plan、Todo 与子代理

这些命令由内置的 nek 扩展提供。

| 命令 | 说明 |
|---|---|
| `/plan` | 安静地进入 Plan 模式 |
| `/plan <需求>` | 进入 Plan 模式并提交规划或修订请求 |
| `/agent` | 退出 Plan 模式，不开始实施 |
| `/plans` | 选择并预览一份已保存的计划 |
| `/nek-build [plan_id] [--fresh]` | 批准并实施一份已审阅的计划修订版本；`--fresh` 在新会话中实施 |
| `/todos` | 显示当前分支的 Todo 列表 |
| `/subagents` | 列出子代理、查看结果、取消运行中的子代理 |
| `/agents` | 列出可用的子代理类型 |

见 [Plan 模式](/guide/plan-mode)、[Todo 列表](/guide/todos)、[子代理](/guide/subagents)。

## 会话与上下文

| 命令 | 说明 |
|---|---|
| `/new` | 开始新会话 |
| `/resume` | 切换到另一个已保存的会话 |
| `/name [名字]` | 设置会话显示名；不带参数时显示当前名字 |
| `/session` | 显示会话信息和统计 |
| `/tree` | 浏览会话树，切换分支 |
| `/fork` | 从较早的一条用户消息创建新会话 |
| `/clone` | 在当前位置复制当前会话 |
| `/compact [说明]` | 手动压缩上下文，可附带说明指引摘要重点 |
| `/import <路径>` | 导入并打开一个 JSONL 会话 |

## 导出与分享

| 命令 | 说明 |
|---|---|
| `/copy` | 复制最后一条助手消息 |
| `/export [路径]` | 导出会话为 HTML（默认）或 JSONL（路径以 `.jsonl` 结尾） |
| `/share` | 上传会话并返回查看链接（Radius，或通过 GitHub CLI 创建私密 gist） |

导出或分享前请检查会话内容，里面可能有提示词、工具参数、命令输出、文件内容和对话中出现过的凭据。

## 运行环境与项目

| 命令 | 说明 |
|---|---|
| `/mcp [login\|logout\|reconnect] [服务器]` | 管理 [MCP 服务器](/guide/mcp)：连接、暴露方式、OAuth |
| `/trust` | 保存当前项目的信任决定，供以后的 nek 进程使用 |
| `/reload` | 重新加载快捷键、扩展、Skills、模板、主题和指令文件 |
| `/hotkeys` | 显示当前生效的快捷键 |
| `/changelog` | 显示更新日志 |
| `/debug` | 把渲染的终端行和会话消息写到 `~/.nek/agent/nek-debug.log` |
| `/quit` | 退出 nek |

## 资源添加的命令

- 扩展可以注册带参数和补全的命令；
- 每个提示词模板以文件名作为命令名，见 [提示词模板](/customize/prompt-templates)；
- Skills 在启用 Skill 命令时以 `/skill:名字` 出现，见 [Skills](/customize/skills)。

添加或修改这类资源后运行 `/reload`。

## 输入框里的其他前缀

| 前缀 | 作用 |
|---|---|
| `!命令` | 执行 shell 命令，输出加入对话 |
| `!!命令` | 执行 shell 命令，输出不发给模型 |
| `@文件` | 模糊搜索并引用文件 |
